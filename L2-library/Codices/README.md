# Codices

Populated by S1 pruning passes. Each row of `REGISTER.tsv` is a provenance entry (branch, path, blob_sha, bytes, source commit, retrieval time) for a `KEPT` Library source row; content is not copied unless noted. Rows tagged `xref-from:` are cross-references to an entry whose primary home is another sub-library. Nothing here is canon (Contract 000 §13).
