## Identity invariant (candidate)

A successful identity-gated operation must be bound to a *witnessed generation* consisting of canonical A-000, canonical `A-000-RESH`, and an explicitly scoped Hebrew Lobby projection. Source-code integrity, marker strings, a process-local `_anchored` boolean, and a digest generated by the same process are **not** independent witnesses. An external reviewed revision record must bind old/new digests and monotonic generation. Every failed check is fail-closed and read-only.

## Proposed change set (56G-k/m/n/o/p/q/r)

1. **k:** define external issuer/witness and immutable revision record; reject missing/unknown witnesses.
2. **m:** canonical sorted JSON for A-000 and Resh alias, sorted-set Lobby membership, with generation binding; no mutable alias reference as a snapshot.
3. **n:** report `core_identity_valid` separately from `resh_projection_valid`; absent optional Lobby is `NOT_CONFIGURED`, not a silent proof of projection.
4. **o:** prepare/validate candidate records and publish atomically; on failure, all records and Lobby membership remain byte-equal.
5. **p:** remove silent `anchor()` from `open_exchanges()`; only explicit witnessed revision can re-anchor.
6. **q:** raise a typed `IdentityInvalid` on invalid identity; valid/no entities returns `[]`.
7. **r (new):** migrate the sole known caller and `exchange()` error convention together, so failure is explicit, never accidental `KeyError`.
