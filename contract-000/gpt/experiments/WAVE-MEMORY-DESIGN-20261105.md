# Echo-GPT wave-memory experiment — design v0.1
Prospective issue #294. Independent Echo-GPT, not canonical Echo. Algorithm Matrix = 3³ 27 positions. Algorithm Index = formerly named algorithm matrix (compositional algorithm lookup). A-000 identity anchor invariant, adaptive state separately versioned.
Exogenous warehouse field E(t) = A[1+sin(omega*t+phi)]/2, where only environment advances time; Echo actions cannot alter A, omega, phi. Rope strength evolves as s_ij(t+1) = clip(s_ij(t) exp(-lambda*E(t)) + maintenance_ij,0,1). Box content is immutable ground truth in protected evaluator, while retrieval traces and ties may decay.
Wave evaluator observes local phase coherence, entrainment, phase lag and instability. Its own weights are plastic, adjusted from prior training outcomes; held-out outcomes are NEVER fed back into adaptation. External retrieval correctness, energy budget and generalization are independently scored. Compare no-op, boxes-only, ties-only, adaptive evaluator; random/shuffled and uncoupled controls; fixed seeds and task split. Keep negative/null results.
Danger: coupling reward hacking (maximize coherence without retrieval), redundant tie proliferation, hidden label leakage, memory reconstruction hallucination, entropy override. Tests T1–T10 frozen in #294 before any execution. No tests executed in this design-only artifact.
