# Glyph pit → polymathematical card → swarm (GPT isolated experiment)

Status: **synthetic, deterministic proof-of-mechanism; not intelligence, autonomous discovery, or Genesis integration.** Test plan posted prospectively to [Issue #107](https://github.com/AGI144348Outlook/Echo_Green_Future/issues/107) before local execution. No modifications to main/Claude/Genesis/Library.

## User-supplied architecture
- 3×3×3 = 27 **stationary, inert loading addresses**, like racecars in the pits.
- Each address is supplied a catalog/index card: one of 22 Hebrew letters or five final forms, with one or more typed interpretations (semantics, mathematics, operations), plus provenance.
- Upon release, each loaded record instantiates a **separately identified subagent**. Its position is not an operating constraint on the swarm.
- Algorithm-000 reproduction is **intentional for subagenting**: an agent stores `origin=Alg-000` and a unique self identifier. A future identity-transition/validation integration layer is to be designed, not assumed to prohibit legitimate reproduction.
- Messages and composed algorithm candidates are separately event logged; no claim of true semantic reasoning.

## Execution
`python -m unittest -v test_prototype.py` or `python test_prototype.py` inside this directory; `python prototype.py` prints demo stats.

## Caveats and falsification
The seed cards are **synthetic placeholders**, NOT authoritative semantics for glyphs and NOT Timothy's full polymathematical index-card schema. Operators are declarative tags; no executable glyph algebra yet. No decentralized swarm scheduler, learning, novel mathematical discovery, versioned replacement validation, persistence store, safeguards for untrusted nested card data, or full Genesis integration. Candidate algorithm means a rule-based composition proposal, not proven algorithmic utility. The user may change card schema and movement laws later. All program output and tests are isolated from paid inference/network/Cloudflare.
