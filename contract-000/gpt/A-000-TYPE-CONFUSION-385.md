# A-000 / Resh detached witness: Python value/type ambiguity — Run385

**Status:** PROPOSED candidate, NOT a frozen RC-R5 test, not a Governor implementation or security approval. **PRE-TEST:** [Issue #13](https://github.com/AGI144348Outlook/Echo_Green_Future/issues/13#issuecomment-6431829836). Source: actual Genesis `genesis-documentary:src/echo_governor_skeleton.py` blob `63eb982989b4f3478d649430b555c8f4ba755c27`; previous candidate `a000_detached_witness_384.py` blob `90282d37f19b1f081bbebecd9bd005629e45268d`, transcribed locally with matching Git blob SHA.

**Problem (source-observed):** Run384 `verify()` compares `current == detached` using Python dict/value equality, then SHA-256 hashes only `detached`. In Python, `True == 1` and `1 == 1.0`; canonical JSON distinguishes their representations. Therefore a state change of numeric or boolean *type* can pass the old check even with an unchanged, externally held receipt. This is distinct from the already-known attacker-reissued receipt/custody weakness.

**Method:** Local Python 3.13, exact Run384 module verified by blob fingerprint; isolated `test_a000_witness_type_gate_385.py` with a synthetic pair and no Genesis imports or writes. First invocation `python3 -I -B -m unittest -v test_a000_witness_type_gate_385.py` failed before test discovery (isolated import path). Corrected invocation: `python3 -I -B -m unittest discover -s . -p 'test_a000_witness_type_gate_385.py' -v`.

**EXECUTION-VERIFIED:** **10/10 methods passed after correcting discovery**. V1 accepted all three altered-state counterexamples (integer→boolean, integer→float, nested integer→boolean); proposed v2 rejected all three using `hmac.compare_digest(canonical(current), canonical(detached))`.
