# A-000 / Genesis — staged rebuild and mixed-view risk (Run449, source-only)

**SOURCE-OBSERVED:** `CatalogBox._put` uses SQLite `BEGIN IMMEDIATE`, checks `expected_revision`, writes card+event, then `COMMIT`. `EchoWorkspace.put_word` awaits that committed result and then calls `self._rebuild()`. In `_rebuild`, `self.matrix` and `self.identity` are assigned **before** the card-indexing loop, and `self.lobby` is assigned **after** the loop. `_gate` checks the new A-000 `identity_symbol` and `status` but no catalog/matrix/lobby epoch. Genesis `AlgorithmMatrix.record` permits ordinary writes to `known['A-000']`; `ReshIdentity.anchor` mutates its nested fields. No independent witness is shown in these inspected paths.

**INFERRED, NOT EXECUTION-VERIFIED:** If `index_dictionary_entry` or subsequent lobby preparation raises after `self.matrix` replacement, the committed catalog card can coexist with a partially rebuilt new matrix and an old lobby object. A successful `_gate` can then coexist with different query views. This is an extension of RC-R5(54)'s already proposed post-commit failure window; it is not evidence a real failure occurred. The source code is single-process; concurrency hazards are a separate future question.

**PROPOSED refinement of unfrozen RC-R5(54), not a new frozen test:** Stage matrix, Resh identity and lobby in local variables; complete all indexing and orientation; verify a deterministic catalog revision/manifest digest and a matching matrix/lobby epoch; then publish the coherent tuple at one controlled boundary. On a crash after catalog commit, recovery should compare durable catalog revision to last witnessed view and log a reconciliation event, not silently assume success. The witness issuer and signing authority remain Timothy's decision; an editable in-DB event is not by itself an independent witness.

**Prospective negative controls, NOT RUN:** inject failure (a) after catalog COMMIT, (b) after new matrix creation, (c) mid-indexing, (d) during lobby preparation, and (e) before publication; after each, check catalog revisions, `matrix`/identity/lobby object coherence, query results, and recovery receipt. Fail if a partial view is silently accepted. No A-000 slot or Echo Equation change; no source or frozen-test edits.
