## Negative controls / discovery

- On an isolated copy, replacing the Dataset A Silver Droplet row with an invalid line made the actual builder **exit 0**, output **5 A rows**, and record **one rejected row**. Replacing a B row analogously made it **exit 0**, output **7 B rows**, and record **one rejected row**. Removing a valid A row made it **exit 0**, output **5 A rows**, and report **zero rejected rows**. Thus exit status alone, or `rejected == []` alone, cannot prove completeness.
- Developed supplemental [HOLD-only pinned receipt guard](f001_dataset_receipt_guard_371.py) and [16-method unittest suite](test_f001_dataset_receipt_guard_371.py). It compares the **two exact public input SHA-256 values**, **three output SHA-256 values**, 6/8 row counts, report shape, zero rejected rows, CSV dimensions, regular files and symlink/size checks. Positive verdict is `VERIFIED_FOR_REVIEW` with `release_authorized: false`. Missing, modified, corrupted or symlinked input/output is rejected.
- Executed `python3 -I -B -m unittest discover -v -p 'test_f001_dataset_receipt_guard_371.py'` from an isolated directory containing the exact reconstructed `rebuild_datasets.py` and `tam-source/` files. **16/16 PASS**, 15.294 seconds. This test file is committed but needs those pinned source fixtures staged locally to rerun; the public-source fixtures and builder were deliberately not duplicated into the GPT mirror.
