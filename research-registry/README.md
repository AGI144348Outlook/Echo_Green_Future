## Registration rules
Each entry needs: stable ID, topic, kind, source branch and path, commit-permalink, claim/question, evidence status (proposal/tested/replicated/refuted/unknown), relationships, and discussion thread ID. Distinguish hypotheses from observations. Do not interpret IETF as Internet Engineering Task Force: here it denotes the independently authored Infinite Expanse Testing Framework, with no affiliation or endorsement.
