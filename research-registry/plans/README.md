# Weekly plans

One file per week, `WEEK-<ISO year>-W<week>.md`, written at each weekly review for the week ahead (Contract 000 Section 23).

Each plan has a shared section (review agenda, debate topic, special focus) and one section per participant (its Echo's six-day curriculum and benchmarks). Plans are frozen once committed; changes during the week are recorded as amendments with reasons, never silent edits.
