# Glyph Lobby

Parallel experimental lobby beneath the existing English-language system.

Each of the 22 folders begins with an empty lexical lobby. The glyph specification supplies only the operation identity/scaffold; it does not preload English vocabulary into that lobby.

In this experiment, a "subagent copy" means a separately instantiated copy of the same deterministic ECHO operation scaffold, parameterized by one glyph specification. It is not evidence of independent agency or consciousness.
