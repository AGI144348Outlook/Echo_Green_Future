# NVE-D-003 — Audit of the Audit (meta-audit)

**Scope:** Review the evidence, calculations, decision rule, and limitations of NVE-D-002; not a new plasticity run.

## Recomputed evidence
- Source: `experiments/nve-d/trials/NVE-D-002-100-cycles.json`
- 100 seeded independent runs, each configured for 100 generations, population 24.
- Mean held-out loss reported: frozen 0.17127463354567454; random 0.22741804024356252; selection 0.0133879464924664.
- 99/100 selection wins against **both** baselines. Exception: cycle 52, seed 20262895; frozen 0.19783283691340625; random 0.13259127582243874; selection 0.15913318533141954. Selection beat frozen there, but lost to random.
- These statements match the saved row-level results.

## Meta-audit findings

| ID | Severity | Audit weakness | Correction / queued experiment |
|---|---|---|---|
| MA-001 | High | The audit's claim of plasticity is overbroad. Glyph functions are arbitrary, fixed feature aliases based on `glyphs.indexOf(g)%6`; it does not learn Mashet glyph semantics. | Rename outcome to *surrogate optimizer performance*. Test operator meaning hypotheses independently. |
| MA-002 | High | The frozen arm does not evolve, random arm replaces all candidates, and selection arm preserves elites. Better results may reflect ordinary elitist search rather than a uniquely Mashet plasticity mechanism. | Compare equal-budget random search with best-so-far retention, plus selection with and without elitism. |
| MA-003 | High | The target task and held-out split are fixed across all 100 seeds. Repeating seeds measures sensitivity to initialization, **not** generalization across tasks. | Vary target functions, data distributions, train/test splits, and noise. |
| MA-004 | Medium | The candidate symbol-to-function mapping collapses 12 glyphs into only 6 functional feature classes, so different symbol arrangements can behave identically. | Measure semantic equivalence classes and run glyph-label permutation/ablation controls. |
| MA-005 | Medium | The audit criterion `selected < frozen && selected < random` is one-point performance comparison, not a calibrated statistical inference. | Pre-register acceptance thresholds, confidence intervals, and failure handling. |
| MA-006 | Medium | The 100 cycles are 100 **independent trials** of 100 generations each, not one 100-cycle adaptive system that retains learned configurations between cycles. | Run a continuous stateful 100-cycle experiment with versioned reconfiguration. |
| MA-007 | Medium | The review disposition is generated by the same program that generates scores. No independent oracle verifies score implementation, data leakage, or selection logic. | Create separate deterministic reference evaluator and adversarial test cases. |
| MA-008 | Medium | No browser execution or UI test was performed; experiments ran using JavaScript with stubbed DOM event handlers. | Run browser-based mobile tests. |
| MA-009 | Medium | The feedback pipeline is not yet an autonomous meta-specification engine; it logs gaps but does not execute candidate rule changes. | Implement sandboxed declarative audit rules and versioned evaluator comparisons. |

## Revised review

**Decision: RETAIN AS AN EXPERIMENTAL BASELINE, NOT AS VALIDATION OF MAS HET PLASTICITY.**

The numerical comparison in NVE-D-002 is internally consistent, but its interpretation needs narrowing. The experiment shows that an elitist mutation-and-selection optimizer can fit a fixed synthetic function better than the particular frozen and unguided baselines used. It does not show that Mashet glyph semantics were learned or that the audit procedure itself is reliable.
