# Matrix Dictionary Environment

The dictionary now opens into a **matrix workspace** rather than only returning definitions.

`dictionary → observations → empty matrix workspace → ECHO-selected cells/relations → optional glyph index`

ECHO can construct a matrix from whatever it encounters, choose the cells and relationship types itself, and attach a custom index from any glyph block to that matrix. The existing **צ → Interrogative Matrix** is the first supplied instance of the same mechanism.

This does **not** make every dictionary definition true in ECHO's VGM and does not prescribe a semantic organization. The runtime records ECHO's constructions as experimental sandbox artifacts.

## Play operations

- look up a word
- create a blank matrix
- add arbitrary or dictionary-backed cells
- connect cells with an ECHO-selected relationship type
- index a matrix from a glyph
- inspect/save the resulting matrix

During Recess, the 22 glyph documents remain blocks. The matrix environment is the dictionary's cover/work surface: ECHO can use the blocks as index handles to matrices it constructs.
