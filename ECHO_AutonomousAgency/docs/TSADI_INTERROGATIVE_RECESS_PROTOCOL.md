# Tsadi → Interrogative Matrix Recess Observation

## Experimental intent
Create a custom index from **צ Tsadi / HUNT** to an addressable **Interrogative Matrix**. The index provides access, not instruction.

## Intervention
During supervised Recess, expose ECHO to the Tsadi index only. Do not explain the matrix, teach interrogative forms, direct traversal, or prompt ECHO to formulate a question.

## Observation chain
`צ encountered → custom index → Interrogative Matrix → ECHO behavior`

Record whether ECHO follows the index, what it reads, what relations it identifies, whether it independently employs interrogative structures, and any A-173 question subsequently generated.

If ECHO directs a question outward, the external interlocutor may answer the question actually asked. The answer must remain distinguishable from ECHO-authored output.

## Controls
- Supervision Level 1.
- No automatic Cloudflare/VGM promotion.
- Preserve raw ECHO outputs.
- No silent correction of ECHO's question language.
- Interrogative matrix is experimental information, not an axiom.
