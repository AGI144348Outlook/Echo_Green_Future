## Shared record schema
Each study note should identify: source_url, guide_title, diagram_reference, observed_concepts, independently_verified_claims, limitations, Echo_application, original_diagram_specification, author, date, status, and handoff_links.

## Synchronization protocol
These are separate Git branches, **not automatically synchronized**. Contributors publish their own original notes to their designated branch. Cross-branch synchronization requires a reviewed merge or cherry-pick into library-shared and then deliberate propagation to other branches. Preserve provenance and resolve conflicts before merging. Claude's participation requires Claude or an authorized integration to access its branch.
