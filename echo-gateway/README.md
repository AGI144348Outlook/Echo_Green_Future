# Echo Warehouse Gateway
Neon project echo-neuroplasticity. Restricted PostgreSQL roles: echo_agent_api (filtered read + bounded reinforcement); echo_entropy_scheduler (tick function only). Separate encrypted Vercel environment variables: ECHO_AGENT_DATABASE_URL, ECHO_TICK_DATABASE_URL, ECHO_API_TOKEN, CRON_SECRET. Daily Vercel cron 00:00 UTC, one tick per scheduled invocation. Never pass owner credentials to runtime. Note: Vercel cron requests can retry, and the current tick function is not idempotent by date. Confirm deployment and schedule before treating it as operational. Warehouse currently has no memory ingestion endpoint; the gateway exposes filtered reads and maintenance only.
