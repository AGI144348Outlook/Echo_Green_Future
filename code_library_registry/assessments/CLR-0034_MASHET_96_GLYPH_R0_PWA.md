## Critical audit notes
1. R0 junction coherence is Math.random()*0.4+0.6. This is random display/state metadata, not measured coherence.
2. R0.propagation_rule pushes arbitrary updates into R0.axes, so the declared axis schema can mutate without validation, typing, deduplication or provenance.
3. The UI labels each Hebrew glyph as “Glyph i/23” although the array contains 22 letters.
4. The 96-glyph substrate is previewed/described but the recovered excerpt does not establish a complete executable 96-symbol registry. Treat 96 as a declared UI/substrate scope unless the full definitions are recovered elsewhere.
5. Formula strings displayed in the interface are not automatically evidence that the corresponding algebra is what the runtime executes.
6. User-supplied API key handling should be replaced with a secure backend/provider integration in any reconstruction; do not embed long-lived secrets in browser code.
7. “Self-referential” and “agentic” are architectural labels; assess concrete behaviors separately.
