# MOD-0002 — Bounded Composition Search

Status: validated and abstraction-frozen before external repository discovery.

This module extracts the deterministic breadth-first primitive-composition mechanism from the autonomous-agency A1 behavioral experiment without carrying over Echo, homework, agency or target-number claims.

- `original/` preserves the exact source experiment and the source branch's license snapshot.
- `generalized/` contains the domain-neutral search engine and application review.
- `validation/` contains independent tests and execution instructions.
- `provenance.json` pins the source branch, commit, path and Git blob.
- `ABSTRACTION_LOCK.json` will record the validated pre-search hashes.

The source license snapshot is preserved as evidence, not endorsed as a resolved outbound license. It references AGPL-3.0 without including the complete AGPL text and adds use restrictions whose relationship to AGPL permissions requires legal/licensing correction. No compatibility or redistribution claim is made.
