# MOD-0005 — Bounded Affinity Admission

Status: validated and abstraction-frozen before external repository discovery.

This module extracts the Hourglass experiment's reusable mechanics: bounded candidate consideration, an admissible similarity window and weighted undirected ties for accepted items.

- `original/` preserves the exact source and source-branch license snapshot in the registry commit.
- `generalized/` removes Echo, LHEA, WordNet, lobby and economy bindings while adding deterministic ordering, explicit decisions and transactional score evaluation.
- `validation/` separates independently written source characterization from generalized tests.
- `provenance.json` pins exact source identity.

The license snapshot is evidence, not a compatibility determination.
